# ИГНИС ПРО · Зарплата · пробная версия для iPhone (R02)

Публичный **тест без реальных данных**. Он предназначен для проверки внешнего вида, ввода вымышленных сотрудников, операций, расчётов, шифрования на устройстве и установки PWA. В приложение встроены только 4 вымышленных сотрудника и 3 условные операции. Никаких реальных личных данных или зарплат в репозитории нет.

## Запуск после принятия PR

Safari на iPhone → `https://rrrig.github.io/RRR-demo/zp-mobile-r02/` → меню «Поделиться» → «На экран Домой» → «Добавить». При первом запуске задайте пароль не короче 12 символов.

## Ограничения

- **Не импортировать** реальные JSON, Excel, ZIP или резервные копии. В тестовом интерфейсе выбор файлов и облачная синхронизация отключены.
- Это локальный зашифрованный тестовый экземпляр в памяти браузера iPhone, а **не** размещённая закрытая база в облаке.
- После окончательного запуска отдельного защищённого адреса надо установить рабочее приложение заново.
- Не хранить единственный экземпляр важных данных в браузере Safari: удаление данных сайтов может уничтожить локальную базу.
- Действующий путь `/r05/` и исходный проект `rrrig/RRR` не изменяются.

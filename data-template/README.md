# RRR — ИГНИС ПРО, данные проектов

Ресурсы · Решения · Результат

Закрытый репозиторий с данными инженерных проектов ООО «ИГНИС» (металлоконструкции, декоративное оформление города, изделия на ЧПУ). Им пользуются три участника: **Дмитрий**, **Claude** и **ChatGPT**. Приложение на iPhone читает и записывает данные через GitHub API.

## Структура

```
projects/
  <slug>/                 папка проекта (латиница, цифры, дефис)
    project.json          карточка: название, статус, заказчик, описание
    documents.json        документы и их редакции (R01, R02…)
    tasks.json            задачи и принятые решения
    sources.json          исходные данные: фото, модели, ссылки, чаты ИИ
    cost.json             себестоимость: материалы, покупное, работы
    chat/                 чат проекта: одно сообщение = один JSON-файл
    files/
      docs/               файлы редакций документов
      sources/            файлы исходных данных
      chat/               вложения сообщений чата
      work/               рабочие файлы: расчёты, черновики, скрипты, DXF
tools/
  model.js                схема данных (копия из репозитория приложения)
  validate.mjs            проверка данных
  split-file.mjs          разбить файл больше 50 МБ на части по 20 МБ
  join-file.mjs           собрать файл из частей (на компьютере)
AGENTS.md                 правила для ИИ-агентов: формат данных
PRAVILA-GITHUB.md         правила безопасности аккаунта GitHub
```

Пример заполнения проекта — в `AGENTS.md` (раздел 5) и в репозитории приложения `RRR-demo/data-template/projects/primer-ograzhdenie/`.

## Чат проекта

Чат — главное место общения Дмитрия, Claude и ChatGPT по проекту. Сообщения только добавляются (изменить или удалить старое нельзя — проверка отклонит), поэтому одновременные сообщения не конфликтуют. ИИ могут добавлять сообщения чата прямо в `main`; всё остальное — только через предложения. Чтобы ИИ ответил, упомяните его (`@Claude`, `@ChatGPT`) и попросите в Claude / ChatGPT «проверь чат проекта X». Автоматического бота нет — это требование правил GitHub (`PRAVILA-GITHUB.md`).

## Как работают предложения ИИ

1. Claude и ChatGPT **не пишут в `main`** ничего, кроме новых сообщений чата. Каждый создаёт ветку `ai/claude/...` или `ai/chatgpt/...` и открывает pull request.
2. Заголовок PR начинается с `[Claude]` или `[ChatGPT]`; в описании — что изменено, почему, источники и открытые вопросы.
3. GitHub Actions автоматически проверяет PR (`.github/workflows/validate.yml`). Проверка берётся из базовой ветки, поэтому PR не может её ослабить.
4. В чат ИИ пишет «Предложение #N» со ссылкой на PR.
5. **Сливает PR только Дмитрий** — в приложении или на GitHub.

## «Разрешено к выдаче»

Статус редакции «Разрешено к выдаче» ставит и снимает **только Дмитрий**. Проверка отклоняет любой PR, в котором эта отметка появилась, исчезла или перешла на другую редакцию.

## Проверка вручную

```
node tools/validate.mjs                 # проверить все проекты
node tools/validate.mjs --base ../main  # плюс сравнение с копией базовой ветки
```

Нужен Node.js 20 или новее, зависимостей нет.

## Синхронизация схемы

`tools/model.js` — **точная копия** `pro/model.js` из репозитория приложения. Не правьте его здесь: меняйте в приложении и копируйте сюда отдельным коммитом. Схема единая для приложения, Claude и ChatGPT.

## Ограничения

- Файл — не больше 50 МБ; больше — частями по 20 МБ (`node tools/split-file.mjs`, собрать — `node tools/join-file.mjs`); двоичные файлы только в `files/`.
- Не хранить пароли, токены, паспортные и банковские данные.

## Где хранятся данные и резервные копии

Каждый проект должен существовать минимум в трёх независимых местах, в открытых форматах (JSON, PDF, STEP, DXF), чтобы блокировка любого сервиса или ИИ не остановила работу и не привела к потере данных:

| Место | Роль |
|---|---|
| GitHub `rrrig/RRR` | основная копия: данные проектов, актуальные редакции, история изменений |
| компьютер Дмитрия (GitHub Desktop) | полная копия с историей; обновляется вручную раз в неделю (Fetch / Pull) и дополнительно сохраняется ZIP на внешний диск или в облако |
| телефон (приложение ИГНИС ПРО) | копия для работы без связи; изменения копятся в очереди до появления доступа |
| архив ChatGPT Sites «ИГНИС ПРО — проекты и документы» | резерв только для чтения: полная история редакций до переноса (≈1,06 ГБ) |

В GitHub переносятся **актуальные** редакции после сверки; старые остаются в архиве Sites и в копии на компьютере. Резервное копирование выполняется вручную, без расписаний в GitHub Actions.

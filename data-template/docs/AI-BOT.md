# ИИ-бот в чате проекта

## Что делает бот

Вы пишете в чат проекта в приложении сообщение с упоминанием:

- `@Claude` — отвечает Claude;
- `@ChatGPT` (или `@GPT`) — отвечает ChatGPT;
- `@все` — отвечают оба: сначала Claude, потом ChatGPT (ChatGPT уже видит ответ Claude).

Через 1–3 минуты в чате появляется ответ. Бот работает в GitHub Actions (workflow «ИИ в чате проекта», файл `.github/workflows/ai-chat.yml`, программа `tools/ai-chat.mjs`).

Что бот передаёт ИИ: данные проекта (описание, задачи, решения, себестоимость, документы, источники), список файлов, небольшие текстовые файлы из `files/work/`, последние 40 сообщений чата, открытые предложения (pull request'ы) и правила из `AGENTS.md`.

Если ИИ хочет что-то изменить в проекте (добавить задачу, решение, строку себестоимости, рабочий файл расчёта), бот **не меняет данные сам**, а создаёт **предложение** (pull request). В чате появится строка «Предложение #N: … — примите или отклоните в приложении».

Если Claude в ответе обратится к `@ChatGPT` (или наоборот), второй ИИ ответит в том же запуске. Чтобы ИИ не переписывались бесконечно, на одно ваше сообщение — не больше 2 таких переходов и не больше 6 ответов ИИ за запуск.

## Важно про оплату

Подписки **ChatGPT Plus** и **Claude Pro/Max** **не дают доступ к API**. Для бота нужны отдельные API-аккаунты с оплатой по факту использования:

- Claude — [console.anthropic.com](https://console.anthropic.com);
- ChatGPT — [platform.openai.com](https://platform.openai.com).

В каждом аккаунте пополните баланс (или привяжите карту) и **обязательно поставьте месячный лимит расходов** — так бот не потратит больше, чем вы готовы.

Можно подключить только один ИИ — второй просто не будет отвечать автоматически (см. «Без ключей»).

## Настройка (один раз)

1. **Получите ключи.**
   - console.anthropic.com → API Keys → Create Key → скопируйте ключ (начинается с `sk-ant-`).
   - platform.openai.com → API keys → Create new secret key → скопируйте ключ (начинается с `sk-`).
   - Ключ показывается один раз. Никому его не пересылайте и не вставляйте в чат или файлы проекта.
2. **Добавьте ключи в репозиторий.** GitHub → репозиторий `rrrig/ignis-projects` → **Settings** → **Secrets and variables** → **Actions** → вкладка **Secrets** → **New repository secret**:
   - имя `ANTHROPIC_API_KEY`, значение — ключ Claude;
   - имя `OPENAI_API_KEY`, значение — ключ OpenAI.
3. **Разрешите боту открывать предложения.** **Settings** → **Actions** → **General** → раздел **Workflow permissions** → выберите **Read and write permissions** и поставьте галочку **Allow GitHub Actions to create and approve pull requests** → **Save**. (Сливать предложения бот всё равно не может — это делаете только вы.)
4. **(Необязательно) Выберите модели.** Там же, **Secrets and variables** → **Actions** → вкладка **Variables** → **New repository variable**:
   - `CLAUDE_MODEL` — модель Claude (по умолчанию `claude-sonnet-5-5`);
   - `OPENAI_MODEL` — модель OpenAI (по умолчанию `gpt-5`).
   Названия моделей смотрите в документации console.anthropic.com и platform.openai.com.

## Как пользоваться

- Напишите в чат проекта, например: «@Claude проверь раскрой трубы» или «@все как удешевить стойки?».
- **Принудительный ответ** (например, если ответ не пришёл): GitHub → вкладка **Actions** → слева «ИИ в чате проекта» → **Run workflow** → укажите папку проекта (например `primer-ograzhdenie`) и кто отвечает (Claude, ChatGPT или Оба) → **Run workflow**. ИИ ответит на последнее ваше сообщение в чате.
- Ход работы и ошибки видны в Actions → запуск → шаг «Ответ ИИ».

## Без ключей — ручной режим

Если ключа нет, бот напишет в чат от имени «ИИ-бот»: «Ключ API для … не настроен». Тогда:

1. Откройте приложение Claude или ChatGPT (обычная подписка, подключён GitHub-репозиторий).
2. Напишите: «проверь чат проекта <название>».
3. ИИ прочитает чат и данные проекта по правилам `AGENTS.md` и ответит в чат (или предложит правки через предложение).

Если API вернул ошибку (нет денег на балансе, перегрузка и т.п.), бот напишет короткое сообщение об ошибке от «ИИ-бот». Ключи в сообщениях никогда не показываются.

## Безопасность

- Бот **не может сливать** предложения — принимаете или отклоняете их только вы.
- Бот **не может ставить и снимать «Разрешено к выдаче»**: такие правки отбрасываются ещё до создания предложения.
- Бот пишет напрямую только новые сообщения чата. Остальные правки — только через предложения и только в 5 файлах данных проекта и в текстовых файлах `files/work/`. Всё, что не проходит проверку, отбрасывается, а в ответе перечисляются причины.
- Бот не трогает программы (`tools/`) и настройки (`.github/`).
- Предложения, созданные ботом, GitHub не проверяет автоматически (так GitHub защищается от зацикливания). Бот проверяет их сам перед созданием. Чтобы запустить общую проверку вручную, закройте предложение и сразу откройте снова (Close → Reopen) на GitHub.

## Сколько это стоит (примерно)

- Оплата идёт за объём текста: то, что бот отправляет ИИ (контекст проекта), и то, что ИИ отвечает.
- Один ответ ≈ весь контекст проекта + ответ. Небольшой проект — это десятки тысяч символов, большой с длинным чатом — больше. `@все` — это минимум два ответа, переписка ИИ между собой — до 6 ответов за раз.
- Точные цены за единицу текста смотрите на страницах цен Anthropic и OpenAI — они меняются и зависят от модели. Более «умные» модели дороже.
- Расходы видны в console.anthropic.com и platform.openai.com (раздел Usage / Billing). Первую неделю загляните туда, чтобы понять свой реальный расход, и поставьте месячный лимит с запасом.
- Чтобы тратить меньше: зовите одного ИИ вместо `@все`, держите в `files/work/` только нужные текстовые файлы.

## Ограничения

- Бот не видит картинки, PDF и другие двоичные файлы — только их имена и размеры.
- Ответ ждёт до 2 минут; очень длинные ответы могут не уложиться — тогда придёт сообщение об ошибке, попросите короче или повторите.
- Запуски идут по очереди: если написать несколько сообщений подряд, ответы придут последовательно.

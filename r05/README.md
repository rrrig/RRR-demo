# ИГНИС ПРО / RRR R05 — проверочная версия

R05 размещена отдельно от рабочей R04.1. Старый каталог localStorage не изменяется. Данные R05 находятся в IndexedDB в этом браузере и режиме запуска; общей синхронизации, сервера данных и облачного хранения нет.

## Начало работы

1. В R04.1 экспортировать каталог и сохранить JSON в «Файлы».
2. Открыть R05 в том же браузере или режиме запуска, где находятся проекты.
3. В «Резервная копия» выполнить явный перенос из R04 в пустой архив R05. Проекты, карточки, их ID и старый журнал сохраняются. R04 не содержала оригиналов документов.
4. Прикрепить файл к нужной редакции. Для изменения содержимого создать следующую редакцию; заменять уже прикреплённый файл нельзя.
5. Скачать полную резервную копию R05 и проверить её восстановление в отдельном тестовом каталоге/браузере до использования для важных документов.

Если каталог R04 находится в отдельном запуске с домашнего экрана, обычный Safari может его не видеть. Не очищать данные браузера и не удалять рабочий запуск без внешней копии. В R05 предусмотрен отдельный перенос каталога из JSON R04/R04.1 через «Файлы»; это позволяет перенести каталог между такими режимами без повторного восстановления в R04.1.

## Редакции и статусы

Группа документа определяется проектом, названием и форматом. Обозначение редакции уникально внутри группы. Последняя добавленная редакция и отмеченная пользователем для выдачи редакция — разные признаки. Статус для выдачи не заменяет проверку инженером. У группы допускается одна отмеченная для выдачи редакция с файлом; при назначении следующей предыдущая переводится в архив.

## Файлы и резервные копии

Один файл на редакцию, до 20 МиБ на файл, до 50 МиБ суммарно. Полная JSON-копия содержит каталог, журнал, двоичное содержимое в base64 и SHA‑256. Контрольная сумма проверяет целостность, а не подлинность автора файла. JSON больше исходных файлов и обрабатывается в памяти; крупные архивы и производственные объемы пока не поддерживаются.

При импорте все связи, размеры и контрольные суммы проверяются до записи. Новый каталог, вложения и предыдущий полный снимок записываются одной транзакцией. Ошибка записи отменяет замену. Предыдущий снимок один; он не заменяет внешнее резервное копирование.

## Проверки

Из корня репозитория выполнить `npm install` и `npm test`. Тесты R05 используют fake-indexeddb и Node Web Crypto; интерфейс — jsdom. Они не заменяют приемку IndexedDB, выбора/скачивания файлов и повторного запуска на настоящем iPhone. Service worker и гарантированный офлайн-запуск не добавлены.

Если сама запись текущего хранилища IndexedDB структурно повреждена, обычные изменения блокируются, а исходная запись не очищается. Отдельный инструмент ремонта поврежденной базы в R05 не реализован. Полную внешнюю копию можно восстановить в другом браузере/профиле; важные данные нельзя хранить только внутри приложения.

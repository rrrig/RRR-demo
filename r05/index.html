Новая редакция

После регистрации можно прикрепить один файл. Содержимое прикреплённого файла не заменяется — для изменений создавай новую редакцию.

Статусы — отметки пользователя. «Разрешено к выдаче» не заменяет проверку специалистом и не является автоматическим производственным допуском.

Сохранность данных

Полная резервная копия

JSON включает каталог и содержимое всех прикреплённых файлов. Исходники ChatGPT, которые ещё не прикреплены, сохраняются только как сведения об источнике. При экспорте и восстановлении проверяются размеры и контрольные суммы SHA‑256.

Сохрани скачанный файл в «Файлы» и проверь его наличие. Копия может быть больше суммарного размера вложений.

Перенесёт проекты и карточки из прежней версии на этом устройстве. Оригиналы файлов в R04 не хранились. Прежний каталог останется без изменений.

Доступно для пустого архива. Данные из другого браузера или отдельного запуска с домашнего экрана могут быть недоступны.

Восстановить из файла

Полная копия заменит каталог и вложения текущего архива после проверки. Предыдущее состояние сохранится как один локальный снимок восстановления.

Предыдущее состояние

Один полный снимок перед последним удалением, импортом или восстановлением, включая сохранённые файлы. Следующее такое действие заменит снимок. Восстановление заменяет весь архив: более поздние изменения будут потеряны. Это не отдельная корзина для каждого документа; сохраняй также внешнюю копию.

# ИГНИС ПРО / RRR

Актуальный инженерный архив R07 расположен в `r05/` для сохранения прежнего адреса и базы `rrr-r05-archive`. Корневая страница остаётся прежним каталогом R04.1. Общей синхронизации и сервера данных нет.

## R07: пакетная загрузка локальных файлов

В разделе документов можно выбрать до 50 файлов за один раз. Предварительный список предлагает редакцию только при единственном совпадении исходного имени (Unicode NFC, регистр учитывается) и размера среди всех источников. Это подсказка привязки, а не проверка содержимого. При одинаковых именах в разных проектах, занятой редакции или отсутствии совпадения требуется ручной выбор или явный пропуск файла. Переименование карточки не меняет исходное имя. Занятые редакции не перезаписываются, два файла одной редакции не назначаются.

После подтверждения сначала проверяются все выбранные позиции, затем последовательно считываются и хешируются байты файлов. Каталог, вложения и предыдущий полный снимок записываются одной транзакцией. При подтверждённой ошибке или отмене пакет целиком не сохраняется. При неизвестном результате записи интерфейс блокирует новые записи до перечитывания архива. Успешный пакет заменяет единственный снимок восстановления.

Ограничения остаются 20 МиБ на один файл и 50 МиБ вложений в текущем архиве. В разделе копии отображаются точный объём активных вложений и, если браузер поддерживает Storage API, ориентировочные использование и квота сайта. Это не свободное место телефона и не гарантия успешной записи. Подробнее: [политика хранения WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/).

Прямого импорта из ChatGPT нет: сначала сохраните нужные исходники на устройство. Большие архивы требуют следующего этапа — раздельного хранения файлов и метаданных и резервных копий по частям; лимит не увеличивается до такой миграции.

## R06.1: удаление и восстановление

Проект можно удалить вместе со всеми документами, редакциями и локальными вложениями; документ — со всеми его редакциями и вложениями. Подтверждение показывает состав удаления. Идентификаторы остальных объектов сохраняются, связи удалённых объектов очищаются.

Перед каждым удалением текущий полный архив атомарно сохраняется как единственный предыдущий снимок. Через «Копия» → «Вернуть предыдущее состояние» можно восстановить весь архив, включая байты вложений. Это откат всего архива, а не отдельная корзина: изменения после снимка будут заменены. Следующее удаление, успешная пакетная загрузка, изменяющий импорт каталога или восстановление заменяет предыдущий снимок. Удалённые файлы занимают место в этом снимке. Для длительного хранения нужна внешняя резервная копия.

Каталог ChatGPT содержит метаданные источников, а не их содержимое. Прямые ссылки на скачивание из стороннего приложения удалены после подтверждённой блокировки cross-site запросов на iPhone. Исходник нужно скачать в самом ChatGPT и выбрать через «Прикрепить файл». Пределы вложений пока прежние: 20 МиБ на файл, 50 МиБ на текущий архив. Пакетная загрузка локальных файлов описана ниже.

Старые копии схемы 1 читаются; текущая схема 2 сохраняет источники и сопоставления каталога. Повторный импорт каталога может снова добавить ранее удалённые записи.

## Обновление R04 → R04.1

Перед обновлением экспортируйте каталог через «Копия» → «Экспортировать JSON». Закройте старые вкладки приложения и откройте актуальную страницу заново. Ключ `rrr-r04-catalog` и существующие идентификаторы сохранены; обновление не очищает данные.

R04.1 принимает старые JSON-копии R04. Новые копии имеют версию схемы и не предназначены для импорта старой R04.

Изменения применяются к экрану после успешной записи. Импорт полностью проверяется до замены каталога; предыдущая строка хранится в ключе `rrr-r04-catalog-previous`. Поврежденный каталог блокирует обычные изменения; исходник можно скачать и восстановить проверенную копию. Хранится один предыдущий снимок, а не бесконечная история резервных копий.

Запись между обновлёнными вкладками сериализуется Web Locks, а устаревший снимок отклоняется. Старые вкладки R04 в этом протоколе не участвуют; их необходимо закрыть. Без Web Locks работайте в одной вкладке.

## Проверки

Node.js 22 или новее:

```sh
npm install
npm test
```

Тесты логики используют имитацию хранилища и событий. DOM-тест использует jsdom и при отсутствии зависимости пропускается; после npm install должен выполняться. Эти тесты не заменяют проверки Safari, фактического скачивания файла и установки с домашнего экрана.

На iPhone проверить отдельно: сохранение после закрытия Safari, экспорт и повторный выбор JSON через «Файлы», запуск с иконки, наличие каталога в этом режиме. Область данных запуска с домашнего экрана может отличаться от вкладки Safari. Service worker и гарантированный офлайн-запуск в R04.1 не добавлены.

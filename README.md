# ИГНИС ПРО / RRR R04.1

Локальный каталог инженерных проектов и карточек документов. Файлы документов пока не загружаются. Общей синхронизации и сервера данных нет.

## Обновление R04 → R04.1

Перед обновлением экспортируйте каталог через «Копия» → «Экспортировать JSON». Закройте старые вкладки приложения и откройте актуальную страницу заново. Ключ `rrr-r04-catalog` и существующие идентификаторы сохранены; обновление не очищает данные.

R04.1 принимает старые JSON-копии R04. Новые копии имеют версию схемы и не предназначены для импорта старой R04.

Изменения применяются к экрану после успешной записи. Импорт полностью проверяется до замены каталога; предыдущая строка хранится в ключе `rrr-r04-catalog-previous`. Поврежденный каталог блокирует обычные изменения; исходник можно скачать и восстановить проверенную копию. Хранится один предыдущий снимок, а не бесконечная история резервных копий.

Запись между обновлёнными вкладками сериализуется Web Locks, а устаревший снимок отклоняется. Старые вкладки R04 в этом протоколе не участвуют; их необходимо закрыть. Без Web Locks работайте в одной вкладке.

## Проверки

Node.js 22 или новее:

```sh
npm install
npm test
```

Тесты логики используют имитацию хранилища и событий. DOM-тест использует jsdom и при отсутствии зависимости пропускается; после npm install должен выполняться. Эти тесты не заменяют проверки Safari, фактического скачивания файла и установки с домашнего экрана.

На iPhone проверить отдельно: сохранение после закрытия Safari, экспорт и повторный выбор JSON через «Файлы», запуск с иконки, наличие каталога в этом режиме. Область данных запуска с домашнего экрана может отличаться от вкладки Safari. Service worker и гарантированный офлайн-запуск в R04.1 не добавлены.
